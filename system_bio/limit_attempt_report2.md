## 3. 결과

### A. 독립 재시뮬레이션: 합의 점수는 재현되지 않음 (사전 지정한 방식, 새 데이터로 1회 평가)
| 점수 (ROC AUC) | 공개 표(모델 450개) | 새 실행(모델 36개) | 새 실행(모델 108개) |
|---|---|---|---|
| 6점수 합의 | 0.917 | 0.661 | **0.745** |
| 규칙 link / topology / topo+link | 0.69 / 0.73 / 0.82 | 0.72 / 0.31 / 0.73 | 0.70 / 0.48 / 0.65 |
| 투표 link / topology / topo+link | 0.83 / 0.76 / 0.80 | 0.73 / 0.51 / 0.55 | 0.79 / 0.55 / 0.63 |

- 앙상블이 커질수록 올라간다(0.661 → 0.745).
- **link-only(파라미터만)는 크기를 맞추면 재현된다.** 공개 데이터를 108모델로 줄이면 투표 AUC 0.71±0.08(새 0.79), 2점수 합의 0.763±0.05(새 0.757).
- **topology 계열은 재현되지 않는다**(규칙 0.73→0.48, 0.82→0.65). 원인 불명. 소프트웨어 차이(돌연변이 방식)가 의심되지만 확인하지 못했다. 누락 예측률이 더 높지만(중앙값 24%, 23% vs 12%) 완전한 모델만 써도 개선되지 않아서 설명이 되지 않는다.
- 새 합의 점수에서 정답 6쌍의 순위: 3, 7, 23, 37, 45, 131. PI가 아닌 쌍 안에서는 AUC 0.93(AK~BI 3위, BI~D1 23위), PI 쌍 안에서는 0.58로 **공개 표 분석(PI 쌍 안 AUC 1.00)과 반대 양상**.

### B. 새 방법: 하이브리드 보정은 효과 없음
- 하이브리드 단독 초과반응 점수 AUC 0.31 / 0.33 / 0.42(예측력 없음), 투표 0.73 / 0.44 / 0.40, 하이브리드 합의 0.38.
- 무작위 앙상블과의 대비(논문 규칙과 같은 형태)는 0.65 / 0.56 / 0.64로 논문 규칙(0.70 / 0.48 / 0.65)과 비슷하다. 한 모델에 두 목표를 담아도 대비를 대체하지 못한다.

### C. 보정 데이터 양: 절반으로 줄이면 나빠지는 방향
| link-only, 모델 36개 | 규칙 | 투표 |
|---|---|---|
| 24노드 전부 | 0.72 | 0.73 |
| 12노드 부분집합 1 | 0.63 | 0.58 |
| 12노드 부분집합 2 | 0.53 | 0.62 |

앙상블 간 쌍 순위 상관은 0.44~0.72로 보정 데이터에 따라 예측이 꽤 달라진다. 더 많은 보정 데이터가 도움이 될 가능성을 시사하지만, 36모델 앙상블의 잡음(투표 AUC 표준편차 약 0.08)이 커서 단정할 수 없다.

### D. 적합도와 예측력
적합도와 단일 모델 AUC의 스피어만 상관이 +0.11~+0.24로 약한 양의 상관이다. 앙상블 절반 비교는 잡음이 커서 결론이 없다(이전의 "조기 종료 모델은 신호 없음" 가설은 이번 데이터로 확인되지 않았다).

## 5. 결론과 정직한 한계
1. **"합의 점수로 한계를 극복했다"는 주장은 독립 검증에서 약해졌다.** 공개 표 분석의 0.917은 재현되지 않았고, 새 데이터로는 0.745(PI 기준선 0.79보다 낮음)다.
2. 재현되는 부분: link-only 계열, 앙상블 크기 효과, 그리고 "정답 6개로는 개선을 입증할 수 없다"는 평가의 한계.
3. 한계 극복에 가장 가능성 있는 방향은 **보정 데이터 추가**(C 결과)이지만 AGS 추가 측정 데이터를 구해 노드에 대응시키는 수작업이 필요하다.
4. 새 구현이 공개 파이프라인(Java, 정상상태 방식)과 완전히 같지 않다. 재현 실패가 구현 차이 때문인지 방법 자체의 한계인지는 구분하지 못했다.
5. 새 앙상블 크기(108개)는 공개(450개)의 1/4이다. 같은 크기로 맞춘 비교는 link-only에서만 가능했다.
