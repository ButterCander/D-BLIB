정독 기준: PDF 12쪽 전체. [논문] = 논문 본문 근거, [코드] = MTEApy 소스 확인, [내 해석] = 논문에 명시 없음.

## 0. 한 문장 요약
키나제 억제제 3종과 시너지 조합 2종을 AGS 위암 세포에 처리 → RNA-seq → DESeq2 → 유전체 규모 대사모델(Human-GEM)에 올려 **어떤 대사 과정(task)이 변했는지** 추정(TIDE, TIDE-essential) → 조합에서만 변한 과정을 "대사 시너지"로 정의.

## 0.5 기초 개념 (정확 정의, 논문 외 배경지식은 표시)

**세포·암**
- 세포주(cell line): 환자 종양에서 얻은 세포를 접시에서 계속 증식하도록 확립한 것. 같은 세포로 반복 실험 가능. 한계: 면역세포·혈관 등 몸속 환경이 없고, 오래 배양하면 변이가 쌓임.
- 위선암(gastric adenocarcinoma): 위 점막의 샘(분비) 상피세포에서 생기는 암. 위암 대부분.
- AGS: 1979년 54세 백인 여성의 위선암 조직에서 확립한 세포주 (ATCC CRL-1739). 알려진 변이(Cellosaurus 기록, 논문 외): KRAS G12D, PIK3CA E453K·E545A, CTNNB1 G34E, RHOA E64del. KRAS 변이 → RAS 상시 활성 → MAPK 경로 과활성. PIK3CA 변이 → PI3K 과활성. 즉 두 경로가 모두 켜진 암세포. (Flobak 2015도 AGS가 MAPK·PI3K·Wnt·NF-κB 경로 구성요소에 변이를 가진다고 서술.)

**신호전달·키나제**
- 신호전달 경로: 세포 밖 신호(성장인자 등)를 단백질들이 차례로 서로를 켜서 핵까지 전달하는 연쇄. 결과로 증식·생존·대사가 조절됨.
- 키나제(kinase): 단백질에 인산기를 붙이는 효소. 인산기가 붙으면 그 단백질이 켜지거나 꺼짐 = 신호의 스위치.
- 키나제 억제제: 특정 키나제에 결합해 활성을 막는 저분자 약. 암은 변이로 경로가 계속 켜져 있어 표적이 됨.

**이 논문의 세 약** (표적·GI50은 논문 Table 2, 작용 설명은 배경지식)
- PI3Ki = PI-103, GI50 0.7 µM. 표적 PI3K(논문엔 PIK3CA = p110α 촉매 소단위). PI3K는 세포막 지질 PIP2에 인산을 붙여 PIP3를 만들고 → AKT → mTORC1을 켬 → 단백질 합성·뉴클레오티드/지질 합성·포도당 흡수·생존. 억제하면 이 성장 프로그램이 꺼짐. (PI-103은 mTOR도 억제하는 이중 억제제로 알려져 있음 — 논문 외.)
- MEKi = PD0325901, GI50 0.035 µM. 표적 MEK1/2. MAPK 경로: 성장인자 → RAS → RAF → MEK → ERK → 증식 유전자 전사. 억제하면 ERK 신호가 끊김.
- TAKi = (5Z)-7-oxozeaenol, GI50 0.5 µM. 표적 TAK1(MAP3K7). TNF·IL-1 등 염증/스트레스 신호를 받아 NF-κB와 JNK/p38을 켜는 키나제 → 생존·염증. 곰팡이 유래 천연물, TAK1을 비가역적으로 억제하는 것으로 알려짐(논문 외).

**약 개념**
- GI50: 대조 대비 세포 성장을 50% 억제하는 농도. 약마다 다름. 이 논문은 단독=GI50, 조합=각 약 GI50의 1/2 (조합의 총 독성을 맞추려는 설계, equitoxic).
- DMSO: 약을 녹이는 용매. 용매만 넣은 세포 = 대조군 (용매 효과를 제거).
- 시너지: 조합 효과가 "두 약이 독립적으로 작용할 때의 예상"보다 큼. 대표 기준 Bliss: 예상 억제율 = Ea + Eb − Ea·Eb (E는 0~1). 관측 > 예상이면 시너지. 이 논문의 "대사 시너지"는 이것과 다른 저자 자체 기준.

**대사**
- 대사: 세포 안 화학반응 네트워크. 대사물질(metabolite)이 효소(enzyme)에 의해 다른 물질로 바뀜. 효소는 유전자가 암호화함.
- 뉴클레오티드: DNA/RNA의 재료. 아미노산: 단백질의 재료. 증식하려면 둘 다 대량 합성해야 함.
- 대사 재프로그래밍: 암세포가 증식에 맞게 대사를 바꿈 (예: Warburg 효과 = 산소가 있어도 포도당을 젖산으로 발효).
- **핵심 가정**: mRNA 양 변화 ≈ 효소 활성 변화. 실제로는 mRNA ≠ 단백질 ≠ 반응 속도(플럭스)라서 이 논문의 가장 큰 근본 한계.

**발현 데이터**
- RNA-seq: 세포 안 mRNA 양을 읽어 세는 기술. 유전자 발현 = 그 유전자가 mRNA로 얼마나 만들어지는지.
- log2FC: log2(처리군 발현 / 대조군 발현). +1 = 2배 증가, −1 = 절반, 0 = 변화 없음.

## 4. 이 논문의 방법

| 용어 | 뜻 | 계산 |
|---|---|---|
| TIDE (Dougherty 2021) | 차등발현 → 대사 task 활성 변화 추정 | 각 반응에 GPR로 log-FC 투영 → task의 flux-carrying 반응 **평균** = 점수 [코드]. 유전자 라벨을 섞은 permutation으로 p |
| TIDE-essential | 이 논문의 변형. 플럭스 분포 없이 필수 유전자만 사용 | task 필수 유전자 log-FC **평균** = 점수 [논문/코드]. 같은 permutation null |
| metabolic score (MS) | task별 점수. − = 하향, + = 상향 | |
| 약한 시너지 (weak) | 조합 점수가 단독 둘의 극값보다 더 극단 | 상향: MS(AB) > max(MS(A), MS(B)), 하향: MS(AB) < min(...) |
| 강한 시너지 (strong) | 단독은 변화 없음, 조합에서만 유의 | MS(AB)≠0 & MS(A)=MS(B)=0 (논문 식. "=0"은 비유의 의미로 보임 [내 해석]) |
| MTEApy | 두 알고리즘의 Python 구현 (COBRApy 기반, MIT) | github.com/bsc-life/mteapy |

## 5. 기억할 숫자
- 6 조건(대조 1 + 처리 5) × 반복 4 = 24 샘플.
- DEG ≈ 2000/조건. MEKi가 단독 중 최다, PI3Ki–MEKi가 조합 중 최다.
- TIDE 유의 task: TAKi 25(본문 30), MEKi 17, PI3Ki 77, PI3Ki–TAKi 55, PI3Ki–MEKi 66 [Table 1].
- TIDE-essential: 14, 15, 10, 11, 18. 전체 69개, TIDE와 겹침 40, ρ=0.93.

- 평균 약 5개 상향 vs 약 40개 하향 task → 대사는 전반적 하향.

## 6. 논문의 이상한 점 (질문 대비)
1. task 수 불일치: 초록·결과 "189개" vs 정제 후 "187개". Table 1의 TAKi TIDE 총계 25는 같은 열의 고유 24 + 공통 6 = 30과 안 맞음(본문 30이 맞음). MEKi TIDE-essential 총계 15도 9 + 7 = 16이어야 전체 69와 맞음. Fig 4B 오른쪽 패널 제목이 "PI3Ki-TAKi"로 잘못 적힘(PI3Ki–MEKi여야 함).
2. 식 (6) 경계 표기 오타 (βi ≤ vi ≤ βi), 본문 "p < 1−10".
3. **다중검정 보정 없음**: task 187개를 p<0.025로 개별 검정 → 우연히 유의한 것 몇 개 예상. permutation p는 하한이 0이라 "p=0" 표현도 가능.
4. **permutation null의 한계**: 유전자 라벨을 무작위로 섞음 → 같은 경로 유전자가 함께 움직이는 상관구조를 무시, task끼리 유전자를 공유해 독립 아님. null 구성(어떤 유전자 풀)에도 민감 (내 재현: 풀을 바꾸면 MEKi 29 → 17개).
5. **강한 시너지는 "유의/비유의" 경계**에 의존: 한 쪽은 유의하고 다른 쪽은 아니라는 차이 자체가 유의한 것은 아님.
6. **대사 시너지 ≠ 성장 시너지**: Bliss 등으로 검정한 것이 아니라 저자 자체 휴리스틱. DESeq2 설계에 상호작용항 없음(저자도 한계로 인정).
7. 한 세포주, 한 시점(24 h), 한 용량(GI50), 반복 4개, **실험 검증 없음** (저자 인정).
8. 단독은 GI50, 조합은 절반 용량 → 용량 차이가 비교에 섞임.
9. TIDE는 task당 기준 플럭스 1개 사용 → FVA에서 149/187이 대안해 존재. 그래서 TIDE-essential 제안. 단 TIDE-essential은 필수 유전자 있는 task만 (배포 데이터 143개 [내 확인]) → 커버리지 낮음.
10. 내 재현(사전점검): DEG 수는 일치, TIDE-essential 근접, TIDE 유의 task 수는 불일치 (PI3Ki 33~44 vs 77).

## 7. 내 연구 관심(암·신약)과 연결
- **조합 요법/시너지**: 같은 AGS, 같은 약 → Flobak 2015 논리(Boolean) 모델이 시너지 예측, 이 논문이 대사 수준에서 설명 (신호 → 대사 층을 잇는 후속).
- **약물 표적 후보**: 시너지 조건에서만 꺼진 경로 = 새 약점. 폴리아민(ODC 억제제 DFMO), 아스파라긴(ASNS/아스파라기나제 치료), 티오레독신 (CHK1 억제제 민감성 [논문 인용 46]).
