## 3. 시도와 결과

### A. 논문 규칙을 올바르게 재현 (E8, E12)
| 전략 | 논문 규칙 AUC [95% 구간] | 상위 35개 중 정답 |
|---|---|---|
| parameters only | 0.686 [0.39, 0.97] (논문 0.69) | 4/6 (논문 4/6) |
| topology only | 0.734 [0.44, 0.97] | 4/6 |
| topology + parameters | 0.823 [0.58, 0.97] (논문 "약 0.8") | 5/6 |

CASCADE 1.0에서는 AUC 0.97, PR AUC 0.92로 논문(0.97/0.91)과 일치한다.

### B. 한계: 가중치(β) 튜닝이 같은 라벨로 이뤄짐 (E8)
논문은 보정 점수와 무작위 모델 점수의 결합 가중치를 정답 라벨로 정한다. 정답 하나를 빼고 튜닝해 빠진 정답을 평가하면(leave-one-positive-out) 성능이 크게 떨어진다.

| 전략 | 같은 데이터 최적 가중치 | 정답 하나 뺀 검증 |
|---|---|---|
| parameters only | 0.84 | 0.70 |
| topology only | 0.77 | 0.54 |
| topology + parameters | 0.82 | 0.55 |

단독 점수는 예측력이 없다(보정 단독 AUC 0.31, 무작위 단독 0.21). 신호는 **둘의 차이**에 있다. parameters only에서 차이 점수가 보정 단독보다 +0.37 AUC 높다(95% 구간 +0.07~+0.70).

### C. 한계: 앙상블 불안정과 누락 예측 (E3, E4, 모델 450개 분석)
- 단일 모델 AUC 중앙값 0.49(무작위), 앙상블 0.83. 모델이 늘수록 상승(10개 0.54, 100개 0.75, 250개 0.80, 450개 0.83).
- 예측의 17%가 누락(고정점 없음 등). 누락을 다루는 5가지 방식(무시, 0 처리, 축소 추정, 완전성 가중, 불완전 모델 제거)은 AUC 0.83으로 거의 같고 순위 안정성도 0.96으로 같다. **누락은 순위에 영향이 없다.** 불완전 모델을 버리면 오히려 0.77로 낮아진다.
- 동점 105쌍(투표 0)을 앙상블 점수로 해소해도 변화 없음.
- 평가: 누락과 불안정은 "문제"가 아니라는 음성 결과.

### D. 한계: 위상(토폴로지)에 의존 (E5, E7)
- 보정 모델과 무작위 모델의 쌍 순위 상관은 투표 비율 0.79~0.85, 앙상블 점수 0.59~0.71. 예측의 큰 부분이 **네트워크 구조로 결정**된다.
- 보정 고유 성분(무작위 점수를 회귀로 제거한 잔차, 라벨 미사용)의 AUC는 0.57~0.65로 약하고 구간이 0.5를 포함한다.
- 보정 전략 간 일치도도 중간(투표 순위 상관 0.63~0.72, 앙상블 점수 0.37~0.62).

### E. 한계: 평가 데이터가 작고 PI 허브에 치우침 (E6, E14, E15, E21, E24)
- 정답 6개 중 4개가 PI(PI3K 억제제)를 포함. "PI 포함 여부" 규칙만으로 AUC 0.79.
- **논문 규칙은 PI에 의존한다**: PI 쌍을 모두 빼면 parameters only AUC가 0.12, topology+parameters가 0.58로 무너진다. 투표 비율은 0.87로 유지.
- 점수를 "약물별 주효과 + 쌍 고유 잔차"로 분해(라벨 미사용): 논문 규칙 성분은 쌍 고유 잔차가 지배(약물 설명 분산 10~24%), 투표 성분은 약물 주효과가 지배(56~72%).

### F. 핵심 시도: 라벨을 쓰지 않는 합의 점수 (E11, E13, E14, E16, E17, E19~E24)
정의: 세 보정 전략의 **논문 규칙 점수 3개 + 보정 투표 비율 3개**를 순위 평균(가중치 학습 없음).

| 지표 | 값 |
|---|---|
| ROC AUC | **0.917** (95% 구간 약 0.83~0.98) |
| PR AUC | 0.31 (구간 0.16~0.69), 논문 규칙 0.22 |
| 정답 순위 (153개 중) | 2, 7, 9, 13, 18, 45 |
| 상위 k개에서 찾은 정답 | k=10: 3개, k=20: 5개, k=35: 5개, k=50: 6개 (무작위 기대 0.4/0.8/1.4/2.0) |
| 상위 15개 | 정답 4개 포함, 나머지 11개는 스크린이 시너지로 부르지 않은 쌍 |

견고성 점검:
- **선택 편향**: 시도한 후보 전체를 한 가족으로 보고, 정답 쌍의 약물 허브 구조를 보존한 순열 검정(약물 이름을 무작위로 섞음)을 했다. 가족 단위 p = 0.0022(후보 16개).
- **정답 하나 뺀 선택 절차 검증**: 후보 16개 중 최고를 고르는 절차의 held-out 성능 0.915. 후보 전체 중앙값은 0.81.
- **부분집합 절제**: 규칙과 투표를 섞은 49개 조합의 AUC 중앙값 0.88(73%가 0.85 이상), 규칙만 0.76, 투표만 0.83. 특정 조합 덕이 아니다.
- **독립 지표 추가**: HSA 점수를 더한 12개 합의도 AUC 0.912.
- **약물 하나 빼기**: 어떤 약물을 빼도 AUC 0.83 이상(중앙값 0.91). PI를 뺀 0.83은 정답 2개 기준.
- **집계 방식**: 순위 평균 0.917, 중앙 순위 0.899, 기하평균 0.904, z점수 평균 0.888, 최고 순위만 0.872. (최악 순위만 쓰면 0.595로 무너지는 것은 당연한 대조.)
- **규칙 블록 대 투표 블록 가중치**: 투표만(w=0) 0.83, w=0.3~0.4에서 최대 0.926, 규칙만(w=1) 0.78. w=0.2~0.6이 모두 0.89~0.93인 **넓은 고원**이라 가중치에 민감하지 않다.
- **음성 대조군**: 보정 투표 대신 **무작위 모델 투표**를 넣어도 합의 AUC 0.922(보정 투표 0.917). 투표 3개만으로도 보정 0.832, 무작위 0.830. 즉 **투표 신호는 보정 없이도 나오는 위상 효과**이고, 보정은 규칙의 "차이"를 통해서만 기여한다.
- **약물 단위 클러스터 부트스트랩**(약물 18개를 재표집): 합의 AUC 95% 구간 0.68~1.00(쌍 단위 0.83~0.98). 논문 규칙 parameters only는 0.05~1.00, 투표 비율은 0.63~0.97. 합의가 가장 덜 불안정하지만 불확실성 자체는 크다.
- **PI 허브 너머**: PI 포함 17쌍 안에서 정답 4개 vs 13개를 완벽히 분리(AUC 1.00, p<0.001), 나머지 136쌍에서 0.83(p=0.06, 정답 2개).
- **학습 가중치는 불필요**: 라벨로 가중치를 학습(leave-one-positive-out)해도 0.89~0.90으로 균등 합의 0.917보다 낫지 않다.
- **계산량**: 진화 50회(모델 150개)로는 합의 AUC 0.83(150회 0.92). 합의가 계산량을 줄여 주지는 않는다.

해석(가설): 규칙 점수는 PI와 관련된 쌍 고유 상호작용을, 투표 점수는 약물 수준 효과와 비PI 쌍을 잘 잡는다. 둘이 상보적이라 합치면 PI 의존성이 줄고 정답 6개가 모두 상위 45위 안에 든다.

### G. 보정이 실제로 기여하는가 (E28~E33)
| 점검 | 결과 |
|---|---|
| 보정 없는 기준선(무작위 모델 투표만) vs 논문 규칙, CASCADE 2.0 | 기준선 AUC 0.830, 논문 규칙 0.686 / 0.734 / 0.823. 차이 −0.14 / −0.10 / −0.01, 구간 ±0.3으로 구분 불가 |
| 같은 비교, CASCADE 1.0 (21쌍) | 무작위 투표 0.63 < 보정 투표 0.83 < 논문 규칙 0.97. **여기서는 보정이 분명히 도움** |
| 조기 종료 모델(최대 세대 전에 종료, G<19, 114개; 목표 적합도 도달로 추정) | 정답 6쌍 모두 시너지 표 0개, PI 쌍 호출 1.5%(나머지 12.7%), 투표 AUC 0.44. 신호는 최대 세대까지 간 336개 모델에서만 나옴 |
| GA 실행 단위 반분(75회 vs 75회, 300회 분할) | 투표 AUC 0.78±0.05(범위 0.61~0.85), 합의 AUC 0.91±0.01(범위 0.87~0.93). 합의가 GA 표본 변동에 훨씬 덜 민감 |
| 링크 투표 앙상블 크기(5~150회) | 합의 AUC 0.89~0.92 유지. 단, 이 곡선은 링크 투표 하나만 줄이고 나머지 5개 성분은 전체 크기라서 **계산량 절감의 증거가 아니다**(전부 50회로 줄이면 0.83, E20) |

해석: 큰 CASCADE 2.0에서는 보정의 이득이 이 벤치마크로 입증되지 않고, 작고 정교한 CASCADE 1.0에서는 입증된다. 조기 종료 모델의 결과는 가설이며(적합도 값 자체가 없어 세대 번호를 대용으로 썼다), 적합도를 직접 받으면 검증할 수 있다.

## 4. 못 한 것 (보정 데이터 확장 후 재학습)
읽기 전용 점검 결과:
- Gitsbe(보정 도구)는 Java 8 + Maven 3.6으로 빌드해야 한다. 이 노트북은 Java 17이 있지만 **Maven이 없다**. `druglogics-synergy`의 GitHub 릴리스에는 배포 파일이 없다(API 응답이 비어 있음).
- 현재 보정 데이터는 AGS의 24개 노드 이진값 1벌(Flobak 2015). 늘리려면 AGS 단백질 활성 공개 데이터를 CASCADE 노드에 수작업으로 대응시켜야 한다.
- 새 파일 다운로드, 소스 빌드, 외부 코드 실행이 필요해 승인 없이는 진행하지 않았다.

## 5. 정직한 한계
1. 모든 증거는 **한 데이터셋(153쌍, 정답 6개, 그중 4개가 PI)**에서 나왔다. 새 스크린에서의 확인은 없다.
2. 합의 점수는 세션 중 약 30개 변형을 본 뒤에 나온 것이다. 가족 단위 검정과 정답 하나 뺀 검증으로 선택 편향을 점검했지만, 완전한 독립 검증은 아니다.
3. 쌍 단위 부트스트랩 구간은 정답 6개를 재표집한 근사다. 정답이 약물을 공유해서 실제 불확실성은 더 크고, 약물 단위로 재표집하면 합의 AUC 구간은 0.68~1.00으로 넓어진다.
4. 점수 부호는 논문의 CASCADE 1.0 결과와 Drabme 문서로 확정했지만, 논문의 R 코드를 직접 돌려 확인하지는 않았다(PR AUC가 논문 0.18 대비 0.22로 약간 다름).
5. 슬라이드는 이 형식의 규칙상 렌더링 확인을 하지 않았다.
